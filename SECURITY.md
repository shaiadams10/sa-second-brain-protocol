# 🔐 Security policy

Please report vulnerabilities privately rather than opening a public issue when a report could expose credentials, local paths, personal data, raw conversations, or a publication bypass.

## Security-sensitive areas

- Source-project write isolation
- Codex automation-account permissions
- Evidence sanitization and prompt-injection handling
- Secret and local-path scanning
- Generated-section preservation
- Checkpoint publication ordering
- Git divergence and force-push prevention
- Public-export allowlisting and redaction

Include a minimal reproduction using synthetic data. Do not attach a real vault, raw session database, credential store, or runtime directory.
