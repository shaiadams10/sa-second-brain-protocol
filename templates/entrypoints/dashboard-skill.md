# Brain dashboard

Run the canonical dashboard-open operation internally when the user asks for the dashboard or a visual brain overview. Never expose raw evidence, credentials, machine paths, or unresolved claims. The generated dashboard is local and derived. Explicit owner-only Knowledge Deck actions may be available, but an agent must never invoke Confirm, Remove, or Undo for the user.
